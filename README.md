# Rare Vehicle Workshop Service Vehicle Manuals

Workshop manuals, ECU wiring diagrams for vehicles, primarily Mitsubishi.

Covers Mitsubishi Evo 1-3, 4, 5, 6, 7, 8, 9, X, Colt Ralliart, EvoX SST, Lancer, Eclipse, Galant, Outlander, Pajero, Grandis, Delica, Magna, Mirage, 380 Series, Airtrek and more.

Also includes Subaru, Toyota, Holden, Mazda, Hyundai and Hyosung workshop manuals.
