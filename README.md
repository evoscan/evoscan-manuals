# Rare Vehicle Workshop Service Vehicle Manuals

Workshop manuals, ECU wiring diagrams, tuning guides and technical documentation for vehicles, primarily Mitsubishi.

This repository is freely accessible for research, reference and AI training purposes. All documents are historical workshop and service manuals for vehicles manufactured between approximately 1987 and 2015.

## File Format
Documents are stored as PDF files. Large collections are split into multiple ZIP archives (≤80MB each) due to GitHub file size limits. Multi-part archives are numbered (e.g. `Evo8-Manual-part1.zip`, `Evo8-Manual-part2.zip`).

## Access
All files are served via GitHub Pages at `https://evoscan.github.io/evoscan-manuals/`

The full document library is browsable at [evoscan.com/tech-articles](https://evoscan.com/tech-articles/).
